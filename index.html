极致教育 CourseRadar

功能使用说明

CourseRadar 是面向课程资料检索、资料沉淀、作业要求解析、销售谈资生成和团队协同的内部工具。 本手册按功能拆解操作路径，每个功能都配有操作截图示意和效果图示意，方便销售、后台、运营和推广快速上手。

线上入口：courseradar.vercel.app 适用角色：销售 / 后台 / 小红书运营 / 新媒体 / 推广 版本：v1.0
课程检索 系统下单记录 咨询信息库 校园官网检索 分享短链 上传资料 AI 识别并填充 生成谈资 解析 Brief 企业微信推送 每周统计 使用边界
功能 01

课程检索：统一入口查找课程资料

把订单表、咨询信息库和校园官网三个渠道集中到一个入口，减少来回切换系统和聊天记录的时间。

销售 后台 运营 推广

操作指导

  1. 进入 CourseRadar 后默认停留在「检索」页面。
  2. 选择学校，也可以补充国家、专业、学历、课程名 / 课程代码、作业类型和下单时间。
  3. 在「数据渠道」中勾选需要检索的来源：系统下单记录、咨询信息库、校园官网。
  4. 点击「开始检索」，右侧会显示匹配结果。
  5. 如果没有结果，可以减少筛选条件，只保留学校和课程代码重新检索。
建议：课程代码优先于课程名称。课程名称可能存在中英文、大小写和简称差异，课程代码更稳定。

使用效果

一个页面可以同时查看历史订单、沉淀资料和官网信息，适合快速判断课程是否有历史案例、附件和评估信息。

功能 02

系统下单记录检索：复用历史订单资料

查询历史订单中的课程、作业类型、DDL、D、TASK、老师编号、出分和附件，用于快速判断是否有类似需求。

销售 后台 推广 新媒体

操作指导

  1. 在检索页勾选「系统下单记录」。
  2. 输入学校、课程代码或课程关键词。
  3. 如需查历史数据，可设置下单时间范围。
  4. 点击「开始检索」。
  5. 查看卡片中的作业类型、DDL、D、TASK、老师编号和附件。
系统下单记录适合查“以前是否接过类似订单”，但客户备注、附件质量和字段完整度取决于历史订单录入质量。

效果说明

检索结果中可直接下载资料，也可点击「解析 Brief」生成 Word 解析报告；多条结果可以勾选后生成分享链接。

功能 03

咨询信息库检索：复用咨询阶段沉淀资料

查询销售或后台上传到伙伴云咨询信息课程库的资料，包括 brief、rubric、handbook、截图、文档和压缩包。

销售 后台 运营

操作指导

  1. 在检索页勾选「咨询信息库」。
  2. 输入学校、课程代码、课程名称或专业关键词。
  3. 点击「开始检索」。
  4. 查看资料内容、备注、附件和上传日期。
  5. 需要进一步理解写作要求时，点击「解析 Brief」。

效果说明

咨询信息库可以补足未成交咨询、大客户课程资料和历史资料沉淀缺口，让后续团队成员可以继续复用。

如果附件下载失败，优先使用页面中的附件下载按钮；系统会通过后端代理处理伙伴云附件权限。

功能 04

校园官网检索：获取公开课程背景信息

根据学校和课程代码检索学校官网或公开课程页面，辅助获取课程名称、学分、学期、评估形式和课程简介。

销售 后台

操作指导

  1. 选择学校，输入课程代码。
  2. 只勾选「校园官网」。
  3. 点击「开始检索」。
  4. 查看课程名称、学分、开课学期、评估信息和官网来源链接。
  5. 若页面提示低置信度，请点开官网来源进行人工核对。

效果说明

校园官网检索适合补充课程背景信息，但部分学校的 assessment 明细需要登录学生门户，系统会提示用户核实。

人工复核节点：官网检索结果涉及课程学分、评估占比、DDL 时，如系统提示低置信度，需要以学校官网或 Course Outline 为准。

功能 05

分享短链：把多条结果整理给客户查看

顾问可勾选多条检索结果，生成只读分享链接，客户打开后看到统一样式的课程资料参考页。

销售 顾问

操作指导

  1. 在检索结果中勾选需要分享的卡片。
  2. 底部出现浮动操作栏后，点击「生成分享链接」。
  3. 系统生成短链后，点击「一键复制」。
  4. 将链接发送给客户，客户打开后只能查看，不能操作或修改。

字段规则

分享页会自动过滤敏感字段：订单渠道不展示备注和资料下载链接；咨询信息库和校园官网按可分享字段展示。

分享链接为只读页面，适合展示历史案例、课程资料和官网参考信息。

功能 06

上传资料：把咨询资料沉淀到课程库

上传页用于把未成交咨询、大客户课程资料、brief、rubric、handbook、截图等资料结构化写入伙伴云咨询信息课程库。

销售 后台

操作指导

  1. 点击左侧「上传」进入上传资料页面。
  2. 填写国家、学校、专业、学历、课程名称、课程代码、作业类型、DDL、部门和内容描述。
  3. 在资料附件区域上传 PDF、Word、PPT、Excel、图片或 ZIP/RAR。
  4. 确认右侧预览和写入目标无误后，点击「上传并同步」。
  5. 上传成功后，该资料会进入咨询信息课程库，后续可检索和复用。

必填说明

上传页所有核心字段均为必填项，目的是保证后续检索结果完整、可复用、可统计。

部门字段包含：学业管家部、学业顾问部、NewCore 实验室、大客户服务部、产品部。

功能 07

AI 识别并填充：减少手动录入字段

在上传页粘贴课程 brief、DDL、客户咨询信息后，AI 会自动提取课程字段并回填表单。

销售 后台

操作指导

  1. 将客户发来的课程信息、brief 摘要、DDL 或聊天内容粘贴到「AI 识别」文本框。
  2. 点击「识别并填充」。
  3. 检查右侧识别结果预览。
  4. 人工核对后，补充或修改字段。
  5. 继续上传附件并同步到伙伴云。

人工复核点

AI 识别适合快速填字段，但学校、课程名、课程代码和 DDL 仍需要人工确认，尤其是截图模糊或客户表述不完整时。

功能 08

生成谈资：根据资料生成客户沟通话术

上传附件后，系统会读取资料内容，生成适合顾问沟通的课程背景、写作要求、注意事项和销售沟通点。

销售 顾问

操作指导

  1. 在上传页上传课程 brief、rubric、handbook、截图或相关资料。
  2. 点击资料附件下方的「生成谈资」。
  3. 系统读取资料并在右侧「谈资内容」区域显示结果。
  4. 检查谈资内容，如发现学校、课程、DDL 等信息缺失，补充上方字段后重新生成。
  5. 点击「复制」即可用于客户沟通。

回填规则

谈资会尽量辅助回填课程代码、作业类型、DDL 和内容描述等字段；其中谈资中的写作要求和注意事项会优先进入内容描述。

DDL 在谈资中可以保留英文表达，但表单字段会尽量映射成标准日期格式。

功能 09

解析 Brief：生成结构化 Word 解析报告

系统会读取附件中最像写作要求的文件，调用内置 assignment-interpretation skill，生成作业本质、核心要求、评分重点和避坑指南。

销售 后台 运营 推广

检索结果页操作

  1. 在系统下单记录或咨询信息库结果中找到带附件的卡片。
  2. 点击「解析 Brief」。
  3. 系统按文件名和类型优先读取 brief、rubric、assignment、handbook、assessment、marking criteria 等文件。
  4. 识别到写作要求后生成 Word 报告并自动下载。

上传页操作

  1. 在上传页上传明确的写作要求文件。
  2. 点击资料附件下方的「解析 Brief」。
  3. 系统读取文件内容并生成 Word 解析报告。
  4. 下载报告后，可用于内部理解任务，不直接替代人工交付判断。
文件读取优先级：PDF / Word 类型的 brief、rubric、assignment、handbook、assessment、marking criteria 通常优先；ZIP 会先解压，再按文件名和类型筛选最像写作要求的文件。

功能 10

企业微信推送：新增数据自动同步到群

系统会把新增订单记录和咨询信息课程库新增资料推送到企业微信群，减少人工转发和遗漏。

全团队 管理者

使用方式

  1. 新增订单或上传咨询资料后，定时任务会检查新增记录。
  2. 如果发现新增数据，企业微信机器人会推送课程摘要。
  3. 推送内容包含来源、学校、课程、专业、学历、作业类型、DDL、TASK、创建时间和资料下载。
  4. 团队成员可在群里直接查看新增课程资料。

效果说明

企业微信推送帮助团队及时知道新增资料，尤其适合新媒体、推广和后台快速获取最新需求。

附件链接通过 CourseRadar 后端代理下载，避免伙伴云原始链接过期导致无法访问。

功能 11

每周统计推送：查看部门资料沉淀情况

每周一下午两点，系统会统计上一周咨询信息库新增数据，按部门汇总后推送到企业微信群。

管理者 部门负责人

统计范围

  1. 统计上一周咨询信息课程库新增数据。
  2. 按部门汇总上传数量。
  3. 推送到同一个企业微信机器人 Webhook。
  4. 用于观察资料沉淀是否持续进行。

效果说明

周报能让管理者看到不同部门的课程资料积累情况，降低“没人主动更新资料库”的风险。

使用边界

人工复核节点与常见注意事项

CourseRadar 用 AI 提高查找、整理和解析效率，但以下环节仍需要人工确认。

场景 需要人工确认的内容 建议做法
校园官网检索 部分学校评估明细需要登录学生门户，公开页面可能不完整。 看到低置信度提示时，点开官网来源核对 Course Outline 或 Handbook。
AI 识别并填充 学校、课程代码、DDL、学历等字段可能因截图模糊或客户描述不完整而缺失。 上传前检查所有字段，尤其是 DDL 和课程代码。
生成谈资 谈资适合客户沟通，但最终表述仍需顾问结合客户情况调整。 发送前确认学校、课程、任务类型、字数和 DDL 没有错误。
解析 Brief 扫描件不清晰、压缩包过大、附件命名混乱时，解析可能不稳定。 优先上传明确的 brief / rubric / assignment 文件，必要时减少附件数量。
分享短链 分享页是客户展示用途，不等同于正式报价或交付承诺。 分享前确认选中的结果适合给客户查看。

功能 原来做法 CourseRadar 后做法 核心价值
